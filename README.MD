# Bar & Restaurant Lounge POS

An offline-capable Point of Sale system for bars, restaurants, and lounges.

## Features
- 🍺 Point of Sale with menu management
- 🚪 Room/table booking
- 👥 User roles (Admin, Manager, Cashier)
- 📊 Dashboard with charts
- 📈 Sales reports
- 🔍 Daily reconciliation
- 🔑 Annual license system
- 🔄 Auto-updates from GitHub

## Download

[**➡️ Download Latest Version**](https://github.com/amrakzos-bot/bar-pos/releases/latest)

## System Requirements
- Windows 10 or newer (64-bit)
- 4 GB RAM minimum
- 200 MB free disk space

## Installation

1. Download `BarPOS-Setup-x.x.x.exe` from the link above
2. If Windows shows "unrecognized app", click **More info** → **Run anyway**
3. Follow the installer
4. Launch **Bar & Restaurant Lounge POS** from the Start Menu
